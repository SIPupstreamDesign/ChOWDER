# [ChOWDER2 User Manual](index.html)

## Content Administrator: Operation Guide

This procedure is for uploading content and controlling its distribution to displays.

### Login Screen

![alt text](../3_1_1.png)

Enter the administrator password for the User ID and Password, and press the Login button.
On the screen after logging in, you can perform the following:

* Add and delete content
* Move content
* Set display viewing positions

***

### Controller Screen Operations

The controller screen is broadly divided into two functions, which can be switched using the buttons on the top left.

![alt text](../3_1_2.png) Switches to the content operation screen. 

![alt text](../3_1_3.png) Switches to the display operation screen. 

![alt text](../3_1_4.png) Hides the operation UI while remaining on the selected operation screen. This allows the work area to be displayed larger. 

Additionally, the following operations are common to both the content and display operation screens:

### Adding Content

![alt text](../3_3_1.png)

You can register content in the content registration field.
The types of content that can be registered are as follows:
* Images (Png, Jpeg)
* Videos (mp4)
* Text
* PDF files
* Site URLs
* GIS content
* Screen sharing

After selecting the content to add, pressing the "Add Content" button will register the content and distribute it to each display.

***

### Managing Content

![alt text](../3_3_2.png)

Content operated on via "3.3.1 Adding Content" will be added to the Content List field. In this field, the following operations are possible:

* Select content
* Delete selected content

***

### Adjusting Content

![alt text](../3_3_3.png)

For content selected within the screen or in the content list from 3.3.2, the following operations are possible in the adjustment field on the bottom left:

* Toggle content visibility (show/hide)
* Adjust content size and position
* Adjust the stacking order of content
* Adjust text content, size, and color (Text content only)
* Delete

### Adding a Display

Adding a display is only possible when there is a connection request from a new display.
When there is a connection request from a new display, an icon ![alt text](../2_ex_1.png) will appear on the top right, and clicking it will automatically transition to the management screen "2.4 Display Registration Screen". By granting permission to the display waiting for connection approval there, it will be registered as a ChOWDER display.

***

### Managing Virtual Displays

 ![alt text](../3_4_2.png)

In the virtual display management field, you can make the following setting changes for the selected site:
* Vertical/horizontal grid line settings
* Virtual display size (vertical/horizontal)
* Whether to enable snap placement of displays against the grid

***


### Managing Displays within a Site

![alt text](../3_4_3.png)

Content operated on via "3.4.1 Adding a Display" will be added to the Display List field. In this field, the following operations are possible:
* Select display
* Toggle selected display visibility (show/hide)

***
